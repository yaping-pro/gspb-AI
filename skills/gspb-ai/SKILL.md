# gspb-ai: 规培轮转手册补录

用于自动化补齐医院教培系统规培轮转手册的病种与操作缺口。基于 `ego-browser` 驱动真实浏览器，保证安全登录、全量预审与零误触。

## 四条不可违背的 Agent 契约（唯一执行路径）

1. **引导登录**：首步执行 `bin/gspb login`。若输出包含 `需要你先在浏览器里登录`，必须把该文本块**完整转述**给用户，并停下等待用户回复「已登录」；**不得**猜测、代填或索要账号密码。
2. **先计划后执行，两个独立进程**：第二步执行 `bin/gspb plan --dept <科室>`。该命令的输出必须**完整原样粘贴到对话中**（配额汇总表 + 全部明细行 + 三个路径行），一条都不许省略或摘要。
3. **审阅门禁**：粘贴完毕后停下，等用户明确回复 `yes`/`确认`/`可以`。用户未明确放行前，**严禁**执行任何 `fill` 命令。用户回 `regen` 则重跑 `plan`；回 `quit` 则停止。
4. **受控消费**：用户放行后执行 `bin/gspb fill --plan <上一步输出的 plan.json 绝对路径>`。每 10 条向用户播报一次进度；输出含 `补录完成` 后执行 `bin/gspb verify` 并粘贴对账表。

## 禁区按钮与安全边界

- **禁区按钮**：全程只点击文字为 `手动录入`、`提交`、`退出` 的按钮。**绝不触碰** `撤回`、`提交审批`、`删除`。
- **停止条件**：遇以下情况立即中止并向用户报告：
  - 用户要求停止；
  - 连续失败 ≥ 3 次；
  - 表单提交后该行实际完成例数未增加；
  - 页面掉落回 `#/login`。
- **数据留痕**：计划与历史断点保存在 `~/.cache/gspb-AI/<工号>/<记录id>/`，支持中断后断点续填。
- **号段安全**：仅使用 18 经验号段加权随机模型，杜绝单调序列与真实患者号码碰撞；可选用户本地黑名单置于 `~/.config/gspb-AI/blacklist.csv`。

## CLI 常用命令

```bash
# 1. 检查或引导登录
bin/gspb login

# 2. 扫描并生成预审计划（指定科室）
bin/gspb plan --dept 口腔修复科

# 3. 执行受控补录（必须提供已审阅 plan.json）
bin/gspb fill --plan ~/.cache/gspb-AI/G1096/00h9m3k3xp51anyucskjjpg9j/plan.json

# 4. 复核达标状态
bin/gspb verify --dept 口腔修复科
```
