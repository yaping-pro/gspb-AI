# gspb-AI：跨 Harness 规培手册补录工具

基于 [ego lite](https://lite.ego.app/) 的跨平台、跨 AI 编程助手（Harness）规培轮转手册自动补录工具。覆盖口腔各科室，零基础医师也能在 1 分钟内极速上手。

---

## 1. 这是什么

`gspb-AI` 是一款专为住院医师规范化培训学员打造的手册自动补录工具。它能够自动连接并驱动真实浏览器，全量扫描轮转手册中的病种与手术操作缺口，生成完整对账表交由你审阅，并在你确认后全自动完成合规录入。

## 2. 它能帮你省什么

出科在即，手动逐条录入几十乃至上百条病种和操作数据不仅费时费力，还容易出现时间越窗、住院号重复或误操作。
使用 `gspb-AI`：
- **从数小时手工复制粘贴缩短至 2 分钟**：全自动逐行填表与提交；
- **每条数据必经你审阅**：填什么、何时填、填谁的名字，全表一目了然；
- **智能名称清洗**：自动剔除主表中的科室与定额尾缀（如 `牙体缺损（25）（口腔修复科）` 自动提纯为 `牙体缺损`），同时完整保护临床分类细节。

## 3. 前置条件

1. **操作系统**：macOS（Apple Silicon 与 Intel 均支持）。
   > 📌 **关于 Windows**：目前暂不支持 Windows，原因是底层浏览器驱动 `ego lite` 官方即将发布 Windows 版，届时本项目将第一时间跟进适配更新，敬请期待！
2. **浏览器驱动**：已下载并打开 [ego lite](https://lite.ego.app/)（下载后双击打开一次即可，它会自动准备好浏览器运行底座）。
3. **环境依赖**：**无需手动安装 Node.js 或 Python！**（工具完全内嵌运行在 ego 运行时中，零环境依赖，开箱即用）。

## 4. 医生极速上手（一键命令，两步搞定）

无论你是刚刚打开 **WorkBuddy**、**Claude Code** 还是系统终端，只需两步：

### 第一步：复制一键安装命令
在终端（或 WorkBuddy 内置终端）中粘贴并回车：

**国内网络推荐（腾讯云 CNB 极速源，无需翻墙，医院内网秒下）**：
```bash
git clone https://cnb.cool/tensor-core/gspb-AI.git ~/Projects/gspb-AI && ~/Projects/gspb-AI/install.sh
```

*(备用 GitHub 源：`git clone https://github.com/yaping-pro/gspb-AI.git ~/Projects/gspb-AI && ~/Projects/gspb-AI/install.sh`)*

> 💡 **懒人小妙招**：你甚至可以直接把整条命令发给 WorkBuddy 对话框，让 AI 替你执行安装！

### 第二步：唤起 AI 助手开始补录
在你的 AI 编程助手（WorkBuddy、Claude Code、Cursor 等）对话框里直接发送一句话：
> **“帮我补录轮转手册”**

接下来助手会：
1. 引导你在弹出的浏览器窗口中登录医院系统（保护密码安全）；
2. 全量扫描当前科室缺口并列出完整的配额统计与明细表；
3. 你审阅回复 `yes` 确认放行后，助手开始全自动安全写入并实时播报进度。

## 5. 它一定会先问过你（严格审阅门禁）

**在得到你的明确许可之前，本工具绝不会向系统写入任何一条数据。**
执行流程遵循双阶段强隔离：
1. **计划阶段（只读）**：扫描缺口，生成 `plan.json` 与 `plan.csv`，并在对话中完整打印待填数据明细；
2. **确认门禁**：AI 助手停下等待你的确认。只有当你明确回复 `yes` / `确认` 时，才会启动写入阶段；如果你想调整，可随时中止。

## 6. 登录说明

- **系统入口**：`https://kygl.pkuszh.com.cn/_jp/`
- **安全与防护说明**：由于医院教培系统具备防自动化安全防护（WAF），AI 工具绝不会要求你提供账号密码，也无法代填登录表单。
- **如何登录**：首次运行时，浏览器会自动停留在登录页，请你在浏览器窗口内手动输入「用户名」+「密码」+「验证码」并点击登录；如果你没有或忘记了密码，可以直接点击页面上的「**手机号登录**」，使用短信验证码快捷登录。登录成功进入系统后，回到对话告诉 AI「已登录」即可。

---

## 7. 安全边界与规范

- **绝不越权**：程序全程仅通过点击 `手动录入`、`提交`、`退出` 完成表单填写，**严禁且绝不触碰** `撤回`、`提交审批`、`删除` 等任何可能破坏既有数据的按钮。
- **本地留痕**：所有的执行计划与填报断点记录均保存在本地目录 `~/.cache/gspb-AI/<工号>/<记录id>/` 下，绝不上传任何外部服务器。
- **脱敏合规模型**：住院号与患者姓名基于统计聚合号段模型加权生成，不发布也不包含任何真实患者样本号码；支持通过 `~/.config/gspb-AI/blacklist.csv` 注入个人防碰撞黑名单。

## 8. 常见问题 (FAQ)

### Q1: 提示「未检测到登录态」怎么办？
A: 请检查浏览器窗口是否已成功登录并停留在教培系统首页。确认可以看到右上角显示的本人姓名与工号（如 `张三【G1234】`），然后重新对 AI 说「我已登录，继续」。

### Q2: 提示「未找到科室对应行」或找不到记录？
A: 默认补录「口腔修复科」，如需补录其他科室，直接对 AI 说即可，例如：
> “帮我补录牙体牙髓科”

### Q3: 提示「记录非待提交状态，已停止」？
A: 本工具仅允许对「待提交」状态的手册进行补录。如果手册已被撤回、已提交审批或已出科归档，系统将自动拒绝写入以保护数据一致性。

### Q4: 填到一半断网或中断了怎么办？
A: 直接对 AI 说「继续补录」，程序具备断点续填能力，会自动跳过已标记完成（`completed: true`）的项，继续补齐剩余缺口。
